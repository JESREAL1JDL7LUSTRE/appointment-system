# Chatbot Integration for Appointment System

## Overview

This documentation describes how to integrate a **Groq-powered chatbot** into the Appointment System. The chatbot can:
- Answer user questions about appointments.
- Provide scheduling assistance in a conversational manner.
- Retrieve data from the existing models (services, staff, appointments, etc.).

## Prerequisites

1. **Groq API Key** – Obtain a key from the [Groq dashboard](https://console.groq.com/).  
2. PHP 8.1+ with `curl` extension enabled.
3. Composer (for installing the Groq client library).

## Environment Configuration

Add the API key to the project's `.env` file:
```dotenv
# Groq API key for chatbot integration
GROQ_API_KEY=your_groq_api_key_here
```
> **Note**: The key should be kept secret and never committed to version control.

## Installation

Run the following command in the project root to install the Groq PHP client:
```bash
composer require groq/groq-php
```

## Implementation Steps

1. **Create a Chatbot Service** – `app/Services/ChatbotService.php`
   ```php
   <?php
   namespace App\Services;

   use Groq\Client; // Assuming the Groq client namespace

   class ChatbotService
   {
       protected $client;

       public function __construct()
       {
           $apiKey = getenv('GROQ_API_KEY');
           $this->client = new Client($apiKey);
       }

       public function ask(string $prompt): string
       {
           // Example request – adapt to Groq's actual API
           $response = $this->client->chat(["messages" => [["role" => "user", "content" => $prompt]]]);
           return $response['choices'][0]['message']['content'] ?? '';
       }
   }
   ```

2. **Create a Controller** – `app/Controllers/ChatbotController.php`
   ```php
   <?php
   namespace App\Controllers;

   use CodeIgniter\RESTful\ResourceController;
   use App\Services\ChatbotService;

   class ChatbotController extends ResourceController
   {
       public function ask()
       {
           $prompt = $this->request->getPost('prompt');
           if (empty($prompt)) {
               return $this->failValidationErrors('Prompt is required');
           }

           $service = new ChatbotService();
           $answer = $service->ask($prompt);

           return $this->respond(['answer' => $answer]);
       }
   }
   ```

3. **Define a Route** – add to `app/Config/Routes.php`
   ```php
   $routes->post('chatbot/ask', 'ChatbotController::ask');
   ```

4. **Create a Simple Front‑end** – `app/Views/chatbot.php`
   ```html
   <form id="chatbot-form" method="post" action="/chatbot/ask">
       <input type="text" name="prompt" placeholder="Ask about your appointment..." required />
       <button type="submit">Send</button>
   </form>
   <pre id="response"></pre>

   <script>
   document.getElementById('chatbot-form').addEventListener('submit', async e => {
       e.preventDefault();
       const formData = new FormData(e.target);
       const res = await fetch(e.target.action, {method: 'POST', body: formData});
       const data = await res.json();
       document.getElementById('response').textContent = data.answer;
   });
   </script>
   ```

## Usage Example

```bash
curl -X POST http://localhost:8080/chatbot/ask -d "prompt=When is my next appointment?"
```
The response will contain a natural‑language answer generated by Groq.

## Testing

Add a PHPUnit test in `tests/ChatbotServiceTest.php` to mock the Groq client and verify that the `ask` method returns the expected text.
